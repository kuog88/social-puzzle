# 🗺️ 石虎探險家・臺灣歷史與地理互動拼圖大冒險

國小五年級社會科（南一版五上 第 1~2 單元）期中考複習用的互動拼圖小遊戲。

- 支援電腦滑鼠拖曳與手機、平板觸控
- 8 個關卡：板塊、地形、圓山／卑南／十三行文化、達悟族、排灣族／魯凱族、阿美族
- 答對會跳出「知識解鎖」說明與 Kling 生成的動畫

## 怎麼玩
直接打開 `social_puzzle.html`，或用 GitHub Pages 的網址在線上玩。

## 替換動畫
把 Kling 影片放進 `videos/` 資料夾，檔名為 `kling_01_plates.mp4` ～ `kling_08_amis.mp4`（對照表見 `kling_prompts.md`）。
影片還沒放進去時，遊戲會自動顯示「Kling 動畫預留位置」。
