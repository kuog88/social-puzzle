## 🗺️ 石虎探險家・臺灣歷史與地理互動拼圖大冒險

國小五年級社會科（南一版五上 第 1~2 單元）期中考複習用的互動拼圖小遊戲。

- 支援電腦滑鼠拖曳與手機、平板觸控
- 18 個關卡：板塊、海域方位、北回歸線、經緯度、地形（山地／盆地／丘陵）、史前文化（長濱／圓山／卑南／十三行）、原住民族（達悟／排灣‧魯凱／阿美／邵／布農／泰雅／鄒）
- 地圖插槽玩法：北回歸線「皮帶扣」、四方「海浪插槽」、考古「挖掘坑」、原住民族「圖騰柱」
- 臺灣地圖底圖由 Kling Image 3.0 依真實海岸線參考圖生成（`assets/taiwan_map.jpg`）
- 答對會跳出「知識解鎖」：Kling 動畫 +「💡 30 秒看懂口訣」+「📝 考試大重點」
- 作答方式：按住拼圖直接拖到地圖插槽（只點一下會提醒要用拖的）
- 弱項自動診斷：每題分成經緯度與海域／五大地形／史前文化與原住民三類，記錄拖錯次數；結算時找出最弱的一類，自動打開「白話知識急救包」（三個分頁，含 Kling 圖解大圖）；遊戲中也可以隨時按右上角「🩹 急救包」打開

## 怎麼玩
直接打開 `social_puzzle.html`，或用 GitHub Pages 的網址在線上玩。

## 替換動畫
把 Kling 影片放進 `videos/` 資料夾，在 `social_puzzle.html` 的 `QUESTIONS` 裡把該題的 `media` 填上檔名（18 題都已放好，對照表見 `kling_prompts.md`）。
影片還沒放進去時，遊戲會自動顯示「Kling 動畫預留位置」。
