## 星星規則與評語（社會各年級統一，2026-11 家長回報修正）

- **題數**：這一關要答對的題目／卡片／步驟數；**答錯**：錯誤的嘗試次數（可以重選的題目，每多選錯一次算一次）。
- ★★★：全對（答錯 0 次）
- ★★☆：答錯 ≤ 題數的 1/4（至少容許 1 次）
- ★☆☆：答錯 ≤ 題數的一半
- ☆☆☆：答錯超過題數的一半 → 不給星，標題改成「再試一次！」，不放彩花，評語鼓勵複習後再挑戰
- 評語依實際表現：3 星「全對！太厲害了！」、2 星「答錯 N 次，很棒！再細心一點…」、1 星「答錯 N 次，過關了！再複習一下…」、0 星「答錯 N 次，這次還沒拿到星星…再挑戰一次吧！」
- 星星只保留最高紀錄；0 星不會蓋掉以前拿到的星星。計時關超過時間的額外規則（四下最多 2 星）不變。
- 延遲事件：關卡內的 setTimeout 一律經過 `later()`，換畫面、回單元、重玩時 `clearLater()` 全部取消，等待中的過關不會記到別的關卡，也不會在單元頁跳出過關視窗。
