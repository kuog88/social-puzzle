# 五年級社會・福爾摩沙時光探險隊（翰林版 五上，115 學年度）

高雄市鳳山區五福國小 五年級上學期社會互動闖關。取代舊版「石虎探險家・臺灣拼圖」（舊版依南一五上做，與學校版本不符）。
- 入口：`index.html`（左上「← 選年級」連到 `../index.html`）；`home-button.js` 由總管加。
- 引擎沿用四、六年級社會（sort / quiz / order），新增 `pinmap`：把卡片拖到臺灣地圖上的 📍（底圖用 repo 共用的 `../assets/taiwan_map.jpg`；讀不到圖時改顯示藍色底，仍可遊玩）。
- 星星存 localStorage `social-g5-stars`；滑鼠拖曳、觸控、先點卡片再點目標都可以；有朗讀按鈕。
