# 五年級社會・福爾摩沙時光探險隊（翰林版 五上，115 學年度）

高雄市鳳山區五福國小 五年級上學期社會互動闖關。取代舊版「石虎探險家・臺灣拼圖」（舊版依南一五上做，與學校版本不符）。
- 入口：`index.html`（左上「← 選年級」連到 `../index.html`）；`home-button.js` 由總管加。
- 引擎沿用四、六年級社會（sort / quiz / order），新增 `pinmap`：把卡片拖到臺灣地圖上的 📍（底圖用 repo 共用的 `../assets/taiwan_map.jpg`；讀不到圖時改顯示藍色底，仍可遊玩）。
- 星星存 localStorage `social-g5-stars`；滑鼠拖曳、觸控、先點卡片再點目標都可以；有朗讀按鈕。

## 進階挑戰題（2026-10）

**做法**：每個單元多加第 4 關「🎯 進階挑戰」（`kind: 'adv'`，選擇題，不計時），接在原本 3 關後面，資料寫在 `data.js` 最後面（`ADV`）。答對後顯示 💡 詳解，陷阱題再多一行「⚠️ 小心陷阱」（`trap` 欄位，25 題都有）。經緯線、文化層、時間軸、地形剖面是程式畫的 SVG（`FIG`）；地圖判讀題用共用的 `../assets/taiwan_map.jpg` 加上甲乙丙丁標記（`XMAP`，讀不到圖時顯示藍底）。星星算法和其他關一樣，大廳總星數變成 20 關 × 3 = 60 顆。原有題目沒有改動。

| 單元 | 5 題考點 | 陷阱重點 |
|---|---|---|
| 一、臺灣的位置與先民足跡 | ①看經緯線圖寫出甲點位置（北緯 23°、東經 121°）②臺灣四周敘述找「錯誤」③文化層剖面推論 ④十三行會煉鐵為何仍是史前時代 ⑤原住民族與環境配對找「錯誤」 | 沒有「東緯／北經」、數字不能對調；澎湖在西不在太平洋；玉器屬新石器、鐵器才是金屬器；史前＝沒有文字紀錄；日月潭→邵族、蘭嶼→雅美族 |

| 三、成為清帝國的領土 | ①時間軸「？」＝牡丹社事件、沈葆楨來臺 ②人物事蹟找「錯誤」③開港四港找「不是」（鹿港）④修水圳後的變化 ⑤哪一個屬於民變 | 沈葆楨（建省前）vs 劉銘傳（第一任巡撫）；一府二鹿三艋舺 vs 開港四港；茶葉是開港後、丘陵；民變反抗官府 vs 械鬥移民互鬥 |

**正確性**：年代沿用本 README 備註已列的一般史實（1624、1626、1642、1662、1684、1786、1860 年代、1874、1885）；人物事蹟、地形與海岸利用都對照原有關卡已採用的課程計畫知識點，不出現本冊沒教的名詞。地形剖面、經緯線方格、文化層都是示意圖，地圖標記位置與原本地圖拼圖的 📍 一致（桃園台地往西微調避免落在山脈上）。

**測試**：`node --check` data.js、game.js 通過；node 腳本檢查 5 個單元第 4 關各 5 題、選項不重複、不和原有題目重複；在瀏覽器（本機伺服器，附共用地圖圖片）逐單元進入進階挑戰、作答（每關先答錯一次）、看到詳解和陷阱說明、過關並記錄星星，大廳總星數顯示 / 60，console 沒有錯誤（只有 favicon 404）。
