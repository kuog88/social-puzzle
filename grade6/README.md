# 六年級社會・未來公民挑戰營（翰林版 六上）

高雄市鳳山區五福國民小學 115 學年度上學期，六年級社會互動闖關網頁。

- **版本**：翰林版 國小社會 6 上，**115 學年度新版**（依五福國小 115 學年度教科書單：社會六年級＝翰林）
- **開啟方式**：直接用瀏覽器打開 `index.html`，不需要網路或安裝任何東西。
- **檔案**：`index.html`（畫面）、`style.css`（像素方塊風格）、`game.js`（遊戲引擎，沿用四年級社會的引擎）、`data.js`（全部題目與關卡內容，老師可直接修改）
- **獨立入口**：只用相對路徑，只引用本資料夾的檔案；左上角「← 選年級」連到 `../index.html`（社會科年級選單）。全站共用的「回遊戲樂園」按鈕（`home-button.js`）**沒有加**，由總管統一加入。
- **操作**：滑鼠、平板觸控都能玩。拖曳題可以「按住拖曳」，也可以「先點卡片、再點區域」。每題都有 🔈 朗讀按鈕（Web Speech API）。
- **星星**：依答錯次數給星（0 次 ★★★、1–2 次 ★★、3 次以上 ★），存在瀏覽器 localStorage（key：`social-g6-stars`），大廳可以清除紀錄。挑戰題有倒數計時，時間到要重新挑戰。

## 備註

- 單元和課次名稱來自上面另一所學校的 115 學年度課程計畫，**沒有實際比對課本**。題目內容是依各課主題和 108 課綱自己編的，不是課本原文。如果課本內容和題目有出入，請老師以課本為準，修改 `data.js` 即可。
- 鄉土素材（高雄加工出口區、中鋼與中船設在高雄、高雄市議會、1999 市民專線、南臺灣太陽能）是為了貼近五福國小學生的生活而加的。
- 第五單元「四角辯論會」課本是實作活動；遊戲只練習流程、分辨事實與意見、理性討論的觀念，實際辯論仍需在課堂進行。
