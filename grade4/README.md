# 四年級社會・家鄉探險隊（南一版 四上）

高雄市鳳山區五福國民小學 115 學年度上學期，四年級社會互動闖關網頁。

- **版本**：南一版 國小社會 4 上（依五福國小 115 學年度教科書單：社會四年級＝南一）
- **開啟方式**：直接用瀏覽器打開 `index.html`，不需要網路或安裝任何東西。
- **檔案**：`index.html`（畫面）、`style.css`（像素方塊風格）、`game.js`（遊戲引擎）、`data.js`（全部題目與關卡內容，老師可直接修改）
- **獨立入口**：只用相對路徑，左上角「← 選年級」連到 `../index.html`（社會科年級選單）。全站共用的 `https://kuog88.github.io/home-button.js`（回遊戲樂園按鈕）**尚未加入**，等使用者確認可以載入外部網站的程式後，再在 `</body>` 前加 `<script src="https://kuog88.github.io/home-button.js" defer></script>`。
- **操作**：滑鼠、平板觸控都能玩。拖曳題可以「按住拖曳」，也可以「先點卡片、再點區域」。每題都有 🔈 朗讀按鈕（Web Speech API）。
- **星星**：依答錯次數給星（0 次 ★★★、1–2 次 ★★、3 次以上 ★），存在瀏覽器 localStorage（key：`social-g4-stars`），大廳可以清除紀錄。挑戰題有倒數計時，時間到要重新挑戰。

## 備註

- 單元和課次名稱來自上面的公開資料，**沒有實際比對 115 學年度的課本**。題目內容是依各課主題和 108 課綱自己編的，不是課本原文。如果 115 學年度課本改版，請老師以課本為準，修改 `data.js` 即可。
- 鄉土素材（高雄捷運橘線鳳山各站、高雄港、小港機場、旗津渡輪、高屏溪、燕巢泥火山、鳳山縣新城、大東文化藝術中心、內門宋江陣）是為了貼近五福國小學生的生活而加的。
- 「校園附近尋寶圖」是**示意圖**，不是五福國小周邊的實際地圖。
