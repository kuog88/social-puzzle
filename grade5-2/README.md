# 五年級下學期社會・時空新聞台（翰林版 五下，115 學年度）

高雄市鳳山區五福國小 五年級**下學期**社會互動闖關。上學期是「福爾摩沙時光探險隊」（像素方塊風），下學期改成**新聞攝影棚**主題：深藍攝影棚＋播報紅／青綠配色、快訊跑馬燈、LIVE 標誌，小朋友當「小記者」，5 個單元＝5 個頻道。

- 入口：`index.html`（左上「← 選年級」連到 `../index.html`）；頁首有醒目的紅色「下學期」標籤，`<title>` 含「下學期」。
- 檔案：`index.html`、`style.css`、`data.js`（題目）、`game.js`（引擎）。不需安裝、可離線（地圖底圖例外，見下）。
- 星星存 localStorage `social-g5-2-stars`，不會和上學期 `social-g5-stars` 混在一起。
- 操作：滑鼠拖曳、平板觸控、或「先點卡片再點目標」都可以；每關有 🔊 唸題目（Web Speech API）。
- 挑戰題有計時（⏱），時間到可再挑戰。星星：見下方「星星規則與評語」。
- 關卡標題元素：頻道頁 `#unitTitle`（class `unit-title`）、關卡頁 `#playTitle`（class `level-title`），供 bgm.js 判斷換曲。
- `home-button.js`、`bgm.js` 由總管統一加入，本資料夾未加。
- 地圖關卡使用 repo 共用底圖 `../assets/taiwan_map.jpg`（和五上同一張）；讀不到圖時改顯示藍色底，仍可遊玩。

## 星星規則與評語（社會各年級統一，2026-11 家長回報修正）

- **題數**：這一關要答對的題目／卡片／步驟數；**答錯**：錯誤的嘗試次數（可以重選的題目，每多選錯一次算一次）。
- ★★★：全對（答錯 0 次）
- ★★☆：答錯 ≤ 題數的 1/4（至少容許 1 次）
- ★☆☆：答錯 ≤ 題數的一半
- ☆☆☆：答錯超過題數的一半 → 不給星，標題改成「再試一次！」，不放彩花，評語鼓勵複習後再挑戰
- 評語依實際表現：3 星「全對！太厲害了！」、2 星「答錯 N 次，很棒！再細心一點…」、1 星「答錯 N 次，過關了！再複習一下…」、0 星「答錯 N 次，這次還沒拿到星星…再挑戰一次吧！」
- 星星只保留最高紀錄；0 星不會蓋掉以前拿到的星星。計時關超過時間的額外規則（四下最多 2 星）不變。
- 延遲事件：關卡內的 setTimeout 一律經過 `later()`，換畫面、回單元、重玩時 `clearLater()` 全部取消，等待中的過關不會記到別的關卡，也不會在單元頁跳出過關視窗。
