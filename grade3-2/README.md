# 三年級下學期社會・小鎮郵差送信記（翰林版 3 下，115 學年度）

高雄市鳳山區五福國小 三年級**下學期**社會互動闖關。上學期是「麥塊校園大冒險」（像素方塊風），下學期換成完全不同的主題。

- 入口：`index.html`，可直接開啟（不用網路、不用安裝）。左上「← 選年級」連到 `../index.html`；`home-button.js` 由總管加。
- 檔案：`index.html`、`style.css`、`data.js`（題目）、`game.js`（引擎）。只用相對路徑、emoji 和 CSS，沒有外部資源。
- 進度（郵戳星星）存在 localStorage `social-g3-2-stars`，不會和上學期 `grade3` 的進度混在一起。
- 滑鼠拖曳、平板觸控、「先點卡片再點目標」都可以玩；每關都有 🔊 唸題目（Web Speech API，zh-TW）。

小鎮有 6 個街區（＝6 個單元），每個街區送 3 封信（動手做／觀念題／挑戰題），每關最多 3 個郵戳 ⭐，全部 54 個。

## 自我測試（2026-10-26）
- `node --check game.js`、`node --check data.js` 通過；另用 node 檢查每張分類卡都有對應的信箱、選擇題選項不重複。
- 嘉家存錢計算逐題重算：10×50=500；500÷30→30×16=480 不夠、30×17=510，17 週；50−35=15；15×8=120；20×15=300。
- 在瀏覽器（localhost）用腳本把 18 關全部玩完，每關都進得去、都能出現結果視窗；分類關另外測試了拖曳放置與答錯扣星。
- 手機寬度（375px）檢查過版面，沒有橫向捲動。
